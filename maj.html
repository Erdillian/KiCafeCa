Mise a jour du calendrier

Lancer la generation automatique depuis le Google Doc

Que fait ce bouton ?

Le calendrier mensuel est genere automatiquement a partir du Google Doc de programmation. Ce bouton lance la mise a jour : telechargement du doc, formatage par l'IA, et publication du nouveau calendrier.

  • 1Telechargement du Google Doc
  • 2Formatage des evenements par l'IA
  • 3Generation du fichier HTML
  • 4Publication sur le site (1 a 3 min)

Configuration

Pour lancer la mise a jour, vous avez besoin d'un token d'acces personnel GitHub avec les droits sur ce depot.
